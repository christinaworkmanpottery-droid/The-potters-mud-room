# Approximate US city locations

`us-cities.json.gz` contains city names, state codes/names and city-centre coordinates derived from kelvins/US-Cities-Database, CSV blob `2efce1ebe149b48dbc1bd8c010d47c608b53c956`:
https://github.com/kelvins/US-Cities-Database

The accompanying MIT license is retained in LICENSE.txt. No member address, precise location, or external geocoding request is involved. City-centre distances are approximate; users in the same city receive distance zero. Radius search currently supports recognized US cities; ordinary name/city/region search remains available worldwide. Ambiguous city names require a state. Do not represent these distances as distances from a member's home.
